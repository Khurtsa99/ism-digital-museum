# Даалгаврын шаардлага ба хэрэгжилт

## 04. Заавал хэрэгжүүлэх боломжууд
| Боломж | Хаана хэрэгжсэн |
|---|---|
| Дижитал үзэсгэлэн (жагсаалт, дэлгэрэнгүй, зураг, тайлбар, он, зохиогч, технологи) | `pages/Exhibits.jsx`, `pages/ExhibitDetail.jsx` |
| Тэнхимийн багш нар (нэр, албан тушаал, хичээл, танилцуулга, зураг) | `pages/Teachers.jsx`, Админ → Багш нар |
| Өдөрлөг ба арга хэмжээ, зурагт цомог | `pages/Events.jsx`, `pages/EventDetail.jsx` |
| Тэнхимийн түүх | `pages/History.jsx`, `pages/Timeline.jsx` |
| ISM Creators (оюутан ↔ бүтээл) | `pages/Creators.jsx`, `pages/CreatorDetail.jsx`, ExhibitDetail дээрх зохиогчийн холбоос |
| Хайлт ба ангилал (нэр, он, ангилал, технологи) | `pages/Exhibits.jsx` (өгөгдлийн сангийн query) |
| Бүртгэл ба эрх | `context/AuthContext.jsx`, `ProtectedRoute.jsx`, RLS |
| CRUD ба зураг upload (Storage) | `pages/MyExhibits.jsx`, `components/ImageInput.jsx`, `components/AdminCrud.jsx` |

## 05. Бүтээлч шийдэл
**ISM Time Machine** (`pages/Timeline.jsx`): түүх, арга хэмжээ, оюутны бүтээл, технологийг нэг шугамд нэгтгэж, төрлөөр шүүж, дарж дэлгэрүүлнэ.

## 07. Хүлээн авах шалгуур
| Шалгуур | Төлөв |
|---|---|
| Нүүр, үзмэрийн жагсаалт, дэлгэрэнгүй хуудас | Хийгдсэн |
| Багш нар, арга хэмжээний зурагт цомог | Хийгдсэн (өгөгдлийг админ хэсгээр оруулна) |
| Supabase-ийн бодит өгөгдөл | Хийгдсэн (бүх хуудас Supabase-ээс уншина) |
| Бүртгэл, нэвтрэлт, гаралт, нэмэх/засах/устгах | Хийгдсэн |
| Хайлт/ангилал, үр дүнгүй үед мэдэгдэл | Хийгдсэн |
| RLS бодитоор хэрэгжсэн | `supabase/schema.sql`. Шалгах: 2 хэрэглэгчээр турш |
| Responsive | `index.css` (@media 760px), гар утсан цэс |
| Бүтээлч шийдэл ажиллана | Time Machine |
| GitHub, README, нийтийн demo | README бэлэн. GitHub/Vercel-ийг ӨӨРӨӨ хийнэ |

## Хэрэглэгчийн эрх
- **Зочин:** үзэх, хайх
- **Бүтээгч:** өөрийн бүтээлийг нэмэх/засах/устгах, профайл засах (RLS: `creator_id = auth.uid()`)
- **Админ:** багш, арга хэмжээ, цомог, түүх, ангилал удирдах, үзмэр нууцлах/устгах (RLS: `is_admin()`)
